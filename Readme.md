# Waq El-Bardi Furnishings Landing Page

A technical repository containing the source code for a responsive landing page developed for "Waq El-Bardy Home Furnishings Factory" (A commercial textile brand located in Egypt).

## Live Demo

- URL: [https://gama110.github.io/warq-el-bardy-furnishings-landing-page/](https://github.io)

---

## Technical Specifications

- **Responsiveness:** Full layout compatibility with desktop, tablet, and mobile displays using CSS flexible layouts.
- **Interactions:** JavaScript-free mobile navigation menu utilizing the CSS `checkbox hack`.
- **Integrations:** Direct action buttons linking to WhatsApp API, Facebook Groups, and the `tel:` communication protocol.
- **Localization:** Configured for Arabic Right-to-Left (`dir="rtl"`) text rendering with Tajawal font family integration.
- **SEO & Social Metadata:** Embedded HTML meta tags including Open Graph (OG) protocol for structural social media link previewing.

---

## Tech Stack

- **HTML5:** Semantic architecture and metadata injection.
- **CSS3:** Custom properties, color palette definitions, typography control, Flexbox, and Grid layouts.
